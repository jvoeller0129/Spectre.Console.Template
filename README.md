# Spectre.Console Template

A .NET `dotnet new` template for building interactive console applications with [Spectre.Console](https://spectreconsole.net) and optionally [Spectre.Console.Cli].

This template lets you quickly scaffold a new project with rich console output, interactive prompts, and structured CLI commands.

---
